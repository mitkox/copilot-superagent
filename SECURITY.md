# Reporting security vulnerabilities

Report suspected vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/mitkox/copilot-superagent/security/advisories/new). If that feature is unavailable, use a private contact method listed on the [maintainer's profile](https://github.com/mitkox). You may open a public issue asking for a private contact, without describing the vulnerability.

Include the affected commit or version, editor/CLI/OS versions, reproduction steps, expected and observed behavior, and likely impact. Use a minimal example with synthetic data. Never include live credentials, private repository content, Teams messages, or ticket/session transcripts in public reports.

This research project has no published security support schedule. Use the current source and review changes before deploying them.

Read the [extension security and deployment boundaries](vscode/SECURITY.md) for execution privileges, credentials, source permissions, privacy, state recovery, and rollout validation.
